INSTALLATION

\------------



1\. Run installer.bat

2\. Complete the installation process at http://localhost:8081 in your browser (should open automatically)

3\. Done! Run launch\_somni.bat to start using somni!







SOMETHING WENT WRONG...

\-----------------------



If you cannot launch somni for whatever reason, try resolving the issue by going through the installer again. This will not delete your images or somni user data.
